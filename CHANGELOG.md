# Changelog

Tous les changements notables apportés à ce projet seront documentés dans ce fichier.

Le format est basé sur [Keep a Changelog](https://keepachangelog.com/fr/1.0.0/),
et ce projet adhère au [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-03-18

### Ajouté
- Structure initiale du thème WordPress
- Système de templates FSE (Full Site Editing)
- Patterns (modèles de blocs) prédéfinis
- Configuration des styles via theme.json
- Styles personnalisés pour les blocs Gutenberg
- Intégration de la police TT Hoves Pro Trial
- Styles de sections personnalisables
- Fonctions d'enregistrement des styles de blocs
- Intégration GSAP pour les animations
- Templates pour différents types de pages (404, archive, single, etc.)

### Technique
- Organisation modulaire du code
- Séparation des styles en fichiers JSON
- Structure de dossiers optimisée pour la maintenance
- Documentation complète de la structure du thème
